# Between Logic & Imagination

A personal portfolio and digital identity website built with React, Vite, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Before publishing

1. Replace the sample hero and gallery images with your own photographs or licensed images.
2. Update project descriptions, screenshots, GitHub URLs and live demo URLs with verified information.
3. Replace `hello@example.com` with your preferred contact email.
4. Add your actual LinkedIn and GitHub profile URLs.
5. Add original writing, photographs and audio recordings when ready.
6. Review the page title and description in `index.html`.

## Content notes

The project entries and stock photography are starter placeholders, not claims about completed public projects or personal photographs. The creative identity `baaya_nedil` links to Instagram at https://www.instagram.com/baaya_nedil/.

## Deployment

This is a standard Vite app and can be deployed to Netlify, Vercel or any static hosting provider. Build command: `npm run build`. Output directory: `dist`.
